# Lend this Mac to a hosted workspace: decisions

One line per review round: what was asked, what changed, in which version. The mock-review skill
keeps this; the build reads it with the approved version.

- Before the first review (v1, 11 November 2026): the independent security review of the
  [design note](../../personal-device.md#11-what-the-security-review-changed) changed v1 in
  place. Lending is turned on, resumed and given folders in a sheet of Gram's own, not on the
  settings page. "Read files without asking" and "Allow this exact command" are gone. The ask
  shows that you wrote to the thread from this Mac and what the command is made of in place of a
  warning list, has no keyboard shortcut, and keeps a withdrawn request on screen.
- Review 1 (v1, 11 November 2026): approved as drawn, with every default in the brief.
- v2 (11 November 2026): draws the two gaps the handoff named, with v1 otherwise unchanged. On
  "2 Lend this Mac", a paused state (three requests in a row refused, unanswered or taken back
  pause that server; lifting it opens the lending sheet) and two unavailable states (no keyring,
  no lock signal) as a line in place of the button. On "The lending sheet", a lift-pause state
  that lists the three requests. Awaiting review.
